# Code of conduct

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and constructive. Critique code and ideas, not people.
- No harassment, discrimination, personal attacks, or publishing other people's private information.
- Assume good faith, and say so when you are unsure what someone meant.

Unacceptable behaviour can be reported privately through GitHub (*Security -> Report a vulnerability* works for any sensitive report, or contact the maintainer through their GitHub profile). The maintainer may remove comments, issues or contributions that do not follow these rules.
